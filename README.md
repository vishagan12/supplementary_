# Supplementary tables

Hyperparameter sensitivity sweeps for the classical restoration pipeline (Tables 6–8): flare threshold τ_flare, Gaussian σ, and gamma γ, with downstream segmentation metrics on the dashcam evaluation set.

**File:** [`appendix_tables.docx`](appendix_tables.docx)

## How to open the document

GitHub **does not preview** `.docx` files in the browser. If you click the filename on the repo page, you may see long XML or encoded text—that is the internal Office Open XML format, not a broken file.

To view the tables:

1. Open the file page on GitHub.
2. Click **Download** (or **View raw**, then save).
3. Open the saved file in **Microsoft Word**, **LibreOffice Writer**, or **Google Docs** (Upload).

Do not edit the file on GitHub’s web editor; that can corrupt binary documents.
